# História da Radiação

Exposição digital em português adaptada da apresentação **História da Radiação**. O acervo reúne uma introdução cronológica, curiosidades históricas e aplicações modernas.

[Visitar o painel](https://luancesarcode.github.io/painel-museu/)

Use os filtros e a busca para encontrar uma ficha. Dentro da ficha, os botões permitem avançar ou voltar pelos resultados. A tecla Escape fecha a ficha.

Para rodar localmente, execute `python3 -m http.server 8000` na raiz e abra `http://localhost:8000`. O GitHub Pages publica a raiz da branch `main`.

`acervo.js` contém as fichas. As imagens e os vídeos em `assets/` foram adaptados da apresentação. As fichas incluem links de referência onde disponíveis.
